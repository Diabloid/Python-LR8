# Python-LR8: Лабораторна робота 8. Unit-тести

## Опис проекту
Репозиторій містить виконання Лабораторної роботи №8 з дисципліни Python:
- Базовий рівень: Модуль \math_utils\ та порівняння тестів на \unittest\ і \pytest\.
- Середній рівень: Модуль \ank_account\ та unit-тести для класу \BankAccount\.
- Високий рівень: Модуль \data_manager\ з тестуванням за допомогою \mock\, параметризації та аналізом покриття коду (\coverage\ $\ge$ 80%).
